Add A Send Modal

**Date**: January 3, 2026  
**Status**: Implemented  
**Extends**: [The OG Spec](./11_25_25.md)
**Author**: Israel Peter Thompson Afangideh

We need our send button's functionality to change. In line with [Now Now Dispatch Prospective Customer Feedback](../../../gtm/customers/feedback/now_now_dispatch/jesse_ceo/)

We want our send button to show a share modal which when the user clicks it should do the following:

1. Show the user various share options on both web and mobile
2. Allow them to share that message in other apps
   - **Mobile (React Native):** Use `Share.share({ message: rewrittenText })`.
   - **Web (React):** - Check `if (navigator.share)`.
     - If supported, call `navigator.share({ text: rewrittenText })`.
     - If NOT supported (Desktop), fallback to the existing "Copy to Clipboard" logic and show a toast: "Sharing not supported on desktop. Copied to clipboard!"
3. The behavior should follow the standard of what other apps do here, eg: you should be able to select recipients within other apps to send it to.
