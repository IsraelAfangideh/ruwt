Lets add end to end testing using Maestro. 

Read the spec and all core parts of the code and then add extensive test cases for each of them. The ideal is that the app cannot be broken in any way that we or a user would notice during manual testing without a test failing and warning us first.

Implement a mock mode so we don't hit the real gemini api

Read the deployment process carefully and add the tests as a step there to make sure we fail if tests are failing.

Make sure tests run on any PRs

If there are any flagrant UI tests that you would want to add but cant because our app would fail them, you can add a markdown file to the root directory listing them and describing them so we can fix them later. And then add the tests
