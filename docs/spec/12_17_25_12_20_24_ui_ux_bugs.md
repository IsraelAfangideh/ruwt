Now that we have successfully deployed the app to internal testing, there are quite a few bugs that we need to fix. When we fix these bugs we should add tests for them so that there are no regressions and these bugs never repeat themselves. 

Bugs
* Chat Input is covered up on android devices by the bottom navigation bar

* There is a moment when the app is opened where the runners have not been opened yet and it just looks like an empty page with Ruwt at the top. We need a good loading state that fits with the rest of the rest of the app. I recommend we use the sine wave animation we have on the website. We bring it to mobile and we use it for instances where we need loading states for full pages.

* We don't have good loading states when the runner is responding, this is really important for our app. We have a loading state on the button when we send, but we should add to this to have a loading state in the chat screen for both the sender and the receiver, whether runner or human, this animation, whatever it is, should fit with the rest of our theme and current animations and logo. We should discuss options for what it should be. 

* The theme doesn't seem to respect system defaults. It should also change as soon as system defaults change, not wait until app is restarted.

* App doesnt have its app icon set properly. We should use brand/mark/png/option4_minimal_monogram/option4_minimal_monogram_800x800.png and delete the old one. Lets bring app.json completely up to date on anything else that needs updating while we are at it
